# Phase E：CSV 性能与兼容性验收

正式测量使用完整 32 字段、两份同规模且不同 seed 的 CSV。所有 worker 顺序运行，
每个构建路径三轮；每项查询一次预热、五次正式样本。对照主源的索引构建加速比，
新路径每轮完整构建两份输入。数值均为本机实测，原始样本、环境、代码与输入哈希保存在 JSON。

151.1 MiB。任务暂存空间采样峰值 2,126,672,032 字节，采样范围见下文限制。
完整 Recording 计时包括 Rerun、查询索引、摘要、蓝图和基本产物校验；导入、检查和 Mapping
分别记录在 `workers.full.builds[].phases`。主源三次的导入/检查/Mapping 中位数约
0.620/7.528/0.012 秒，不能把 149.570 秒解释为包含所有前置操作的端到端时长。

完整聚合与独立 CSV oracle 逐值一致；完整诊断与冻结 C3 实现的报告哈希一致。
原始报告明确标记每项硬门槛，不把 SQLite 游标返回行数解释为引擎扫描数。
P95 是五次正式样本的最大值，属于热缓存单机结果，不代表生产 tail SLO。

## Phase D 与压力测量

Phase D Small 对比旧/新 writer 的全部 960 万业务组件；Medium 仅新 writer，
完整解码 9600 万业务组件并通过 RRD verify。Medium 的 sdk_parity 为 null，
没有未运行的旧路径对照。Small 单次完整构建只报告 elapsed，不生成 P95。

Large 状态：`succeeded`。该档为单份 1200 万行输入的新完整 Workspace 压力测试，
子进程预算为 30 分钟/2 GiB RSS，输入生成在该预算之外，不验收交互延迟。
输入为 3,805,308,641 字节，完整 Recording 构建 612.789 秒；实际写入 3.84 亿个逻辑值，
无 EAV 回退，生成约 9.887 GB RRD，`rerun rrd verify` 返回 0。
进程内 OS 峰值 286.3 MiB，任务暂存空间采样峰值约 8.033 GB。

## 失败与测量限制

- 最初的 Phase D Small 在完成旧 writer 后遇到 Windows 采样目录删除竞态，未形成完整报告。
  采样改为容忍目录消失的 os.walk，补上异常时先终止所属 worker 再清理，随后独立重跑成功。
- `initial_smoke_excluded.json` 保留首轮工具误将 Medium 的 3× 条件应用到 Smoke 的失败记录，
  不进入最终验收。后续索引写入与精确摘要优化的早期调优报告保留在本机 results 目录。
- `full_build_outlier_excluded.json` 保留完整构建出现 466 秒异常后主动停止的运行，
  未完成三轮，不纳入最终验收。随后限制 typed 任务取消状态的数据库轮询频率，
  保持标记文件即时检查，并用同一校验输入重新运行全部正式计时。
- Phase D Small 的首轮对照期间存在本地代码/测试工作，只用其作业务兼容性及单次耗时记录，
  不宣称稳定性能倍数；Phase E 最终正式轮次使用固定生产代码，独立顺序测量。
- 暂存磁盘峰值只覆盖任务所有的 float spool、SQLite WAL/journal 和 CSV sort cache，
  不包含不可观察的 SQLite 原生临时 I/O；RRD/RBL 与 Catalog 大小单独记录。
- 正式测量后补齐了 Core 同步批量重试的策略持久化，以及 Catalog/项目暂存/输出不同磁盘时的预算，
  并将批量估算接入所选策略。写入、时间转换、摘要、查询和 `build_recording` 执行代码保持一致，
  改动仅涉及批量入口与磁盘预检。测量时和交付时的文件哈希、AST 差异及可逆补丁见
  `verification.json` 和 `post_measurement_*.patch`。交付版另跑完整 Smoke；上述 Medium/Large
  原始数据没有替换，也没有在这些补充修复后重跑，不能宣称其完整文件哈希与交付版相同。
- 当前环境没有 Rust 工具链，也不能在本机完成 Linux/macOS 原生安装包验收。
  Quality 中的跨平台存储矩阵已配置，尚未运行的外部 CI 不视为通过。

## 默认与回退

默认值保持 `legacy`，直到所有性能和跨平台发布门槛均通过。
`--query-storage auto`、API 同名参数及桌面“自动”选项可显式使用新路径。
v5 只增加摘要表，不重建旧 Recording；项目包仍不携带查询索引。

各文件内容哈希及原始来源见 manifest.json；回归验证记录见 verification.json。

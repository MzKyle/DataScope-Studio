# 功能边界收敛：实现与验收

日期：2026-10-31。产品边界以根目录《产品设计.md》为准。

## 实现

- 主导航收敛为快速查看、项目、设置；记录详情为概览、检查、筛选。自定义查询、对比、批量任务、预设与插件保留在对应任务上下文。
- 快速查看与各项目导入草稿独立；上下文切换清除查询/报告结果并忽略迟到响应，后台任务继续运行。
- Quick Inspect 新增可选 build_query_index，默认 true 保留旧请求行为；桌面显式 false，跳过查询 writer 和摘要。正式项目、CLI、批量构建与 legacy 默认值不变。
- 转入项目重新导入原数据，保留当前 Mapping，更新 source/mapping/recording 标识并重新校验；不自动构建或迁移临时产物。失败重试复用已有目标，清理失败不会回滚保存结果；已失效会话视为清理完成。
- 桌面与 HTML 使用规则检查得分、Topic 时间范围差异和低置信度/无检测结果样本等措辞。算法、公开规则 ID 和 JSON/CSV 数据契约不变。

## 自动检查

仓库 PR 快速门通过：629 项 Python 测试、5 项按环境跳过，75 项前端测试，前端生产构建、release sanity 和 cargo check --locked。后续新增清理失败/会话失效回归后，前端全套 76 项通过。

HTML 的历史逐字节比较调整为验证内嵌完整报告；JSON/CSV 仍逐字节保持一致。轻量构建测试验证不调用索引 writer、查询表为空、失败清理、磁盘预算及 RRD 业务组件/时间轴等价。

为运行 Windows 检查，将 Rust 工具链放在忽略目录 .tooling，未修改系统 PATH 或增加应用依赖。PR 检查入口在执行时解析 npm.cmd，以支持 Windows CreateProcess。

## 真实桌面验证

通过 Windows 原生 Tauri + WebView2 的 CDP 操作真实页面，完成三入口导航、Mapping 修改、跳过索引生成、保留映射转入项目、项目内重建、记录检查、限定记录筛选及高级设置访问。验证期间没有页面脚本异常。截图和本机详细日志保留在忽略目录 .tooling/convergence-native-*。

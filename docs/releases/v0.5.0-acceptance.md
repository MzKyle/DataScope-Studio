## 三分钟流程走查与真人观察

自动化从安装后应用启动开始计时，通过系统文件选择框选择 CSV，而非向页面直接填路径。
包含一次 Mapping 修改、实际生成和打开 Rerun；截图确认曲线和日志已加载，页面脚本异常为 0。

| 自动化观察点 | 从应用启动计时 |
| --- | ---: |
| 主入口可用 | 1.686 秒 |
| 有效预览 | 3.639 秒 |
| 完成生成 | 4.144 秒 |
| Rerun 数据窗口可见 | 11.754 秒 |

这是已经多次运行过的本机小文件自动化走查，包含缓存影响；不代表冷机性能、独立新用户
发现入口的时间或所有机器的体验。首次打开 Rerun 时观察到 Windows 网络访问提示，
没有授予网络访问；截图中本地曲线和日志已加载。该系统提示的处理成本需在真人观察中记录。

独立新用户观察尚未完成，参与者、求助、犹豫和误操作均没有可报告的真人记录。不能把以上
自动化耗时登记成真人三分钟协议通过。观察者应按[原协议](../usability/new-user-3min-test.md)
给首次使用者一句任务：“请试着用这个软件查看这份机器人数据”，记录 30/120/180 秒节点、
系统提示和首次求助；只修阻断首次回放的问题。

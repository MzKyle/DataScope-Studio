# DataScope Studio v0.5.0

状态：发布候选，尚未推送版本标签或公开安装包。当前公开版本仍为
[v0.3.1](https://github.com/MzKyle/DataScope-Studio/releases/tag/v0.3.1)。

## 变更

- 主导航统一为快速查看、项目和设置。首次回放无需先创建项目；记录详情提供概览、检查和筛选。
- 桌面快速查看跳过查询索引和 typed 摘要，继续生成并校验 RRD/RBL。旧 API 请求默认建立索引，正式项目、批量任务和 CLI 保持原行为。
- 快速查看转入项目保留用户修改的 Mapping，重新导入、分配新标识并校验；由用户在项目中重新生成记录。重试复用已创建的目标，清理失败不会回滚保存结果。
- 检查文案明确为规则检查得分、Topic 时间范围差异及低置信度或无检测结果样本；结构化结果和评分算法保持兼容。
- 包含 CSV 批量写入、查询聚合和存储兼容改进，查询存储默认仍为 legacy。
- 修复非有限数值时间在部分 macOS/pandas 环境被解析成极大日期的问题，统一标量、批量查询及无效时间回退行为。
- 修复 macOS 任务退出期间进程组信号返回 EPERM 的清理竞态；回退到已归属的 worker PID，仍保留真正的权限错误。

## 兼容与限制

已有项目、Mapping、项目包、规则 ID 和 JSON/CSV 字段继续兼容。没有新增生产依赖。
快速查看的临时记录没有查询索引；需要筛选或检查时，先保留 Mapping 转入项目并重新生成记录。
安装包未签名，包含独立 Python runtime、本地 API 和 Rerun，不要求用户安装开发环境。

## 发布验收

最终候选提交需要通过三个平台的存储兼容 CI、PR 门和 Release 严格门，并完成
Windows、Linux 及两种 macOS 架构的安装包冒烟。实际结果统一记录在
[v0.5.0 验收记录](v0.5.0-acceptance.md)。

首次使用观察遵循[三分钟协议](../usability/new-user-3min-test.md)。自动化桌面走查
只能证明流程可以执行，不能替代独立新用户观察。
